# NetSuite se demuestra solo con SuiteQL y CSV import contra un esquema sintético

La experiencia real con NetSuite incluyó queries SuiteQL de solo lectura ejecutadas vía un conector MCP, cargas por CSV import revisadas por una persona y un RESTlet con autenticación TBA (OAuth 1.0), construido con Claude Code, del que un job nocturno leía la cartera. Este repo demuestra solo la parte de SuiteQL y CSV import. El módulo de NetSuite usa un esquema SQLite sintético que imita las tablas de SuiteQL (`transaction`, `transactionline`, `transactionaccountingline`, `account`, `accountingperiod`, `classification`) y no incluye cliente REST, RESTlet ni SuiteScript. Un RESTlet necesita una cuenta real para desplegarse y probarse, y un cliente REST contra un mock solo probaría el mock.
